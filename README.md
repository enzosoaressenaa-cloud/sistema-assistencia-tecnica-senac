Objetivo
Desenvolver um sistema desktop para auxiliar no gerenciamento de uma assistencia tecnica, permitindo organizar clientes, equipamentos, tecnicos e ordens de serviço.

## funcionalidades
-login de acesso
-dashboard
-cadastro e consulta de equipamentos
- cadastro e consulta de tecnicos
- cadastro e acompanhamento de ordens de serviço
´- alteração do status das ordens de serviço
- persistencia dos dados utilizando mysql
-acesso ao banco de dados utilizando jdbc
- organização do projeto utilizando orientação a objetos e padrao DAO
